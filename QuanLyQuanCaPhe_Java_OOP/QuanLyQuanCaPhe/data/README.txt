File cuahang.txt được tạo tự động trong lần chạy đầu tiên.
Không cần tự tạo file rỗng: một file rỗng có sẵn sẽ bị xem là file dữ liệu lỗi.
cuahang.txt.bak là bản trước lần ghi gần nhất.
Muốn có dữ liệu mẫu mới, chạy Main --data data/demo_moi.txt.
Hạn sử dụng của dữ liệu mẫu dựa trên ngày tạo file, không tự kéo dài mỗi lần mở.
